# Laravel Reports

> [!WARNING]
> **Work in progress — do not use yet.**
> This package is under active development and is **not functional**. The public API will
> change without notice, and there is no release. Do **not** install it in any project.

`guggach/laravel-reports` will provide banded, print-ready reports for Laravel: report
classes rendered server-side with PHP/Blade, reusable layouts, filters, presets, and
HTML/PDF output. The design is described in [`docs/spec.md`](docs/spec.md).

The original idea notes are kept in [`docs/spec-notes.md`](docs/spec-notes.md).

## Status

- No usable release exists.
- Nothing in this repository is stable or supported.
- Do not use it in production or any project.

## Planned requirements

- PHP 8.3+
- Laravel 11, 12 or 13

```bash
composer install
```
